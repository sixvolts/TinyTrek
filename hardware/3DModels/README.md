# 3D models:

You will need a 3D printer with at least an 8inx8in (203mmx203mm) print area to print the chassis.

# Required models:
There are 3 Required models: TinyTrekV1pt5.stl, battExtender.stl, in this repo and m12_flashlight_lower_body at the following link: https://www.printables.com/model/96306-milwaukee-m12-flashlight-with-adjustable-head

# Optional models:
Cam Bracket.stl and snapConnectorBracket.stl are for optional additions to the project.
