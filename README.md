TinyTrek is an open-source learning platform for teaching concepts from modern connected vehicles. The platform is based around a small "vehicle" that runs on a collection of microcontrollers and a Raspberry Pi. Major subsystems typical to a vehicle are implemented, such as a BMS, Motor Controllers, Sensors, Over-the-Air updates (OTA), multiple on-vehicle communication busses, and other features. 

The Raspberry Pi image is build with yocto, and the OTA system uses Mender. The body of the vehicle is 3D-Printed and designed to be assembled by the student or researcher.
